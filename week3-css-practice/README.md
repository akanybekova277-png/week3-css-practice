## Project Description

This website presents my solutions to 15 CSS practice exercises organized into three categories: Beginner, Intermediate, and Challenging.

## Structure

- `index.html` — Home page with navigation to all exercises
- `css/styles.css` — External stylesheet
- `beginner/ex1.html` to `beginner/ex5.html`
- `intermediate/ex6.html` to `intermediate/ex10.html`
- `challenging/ex11.html` to `challenging/ex15.html`
- `assets/` — Images and other assets

## Features

- Semantic HTML5
- External CSS stylesheet
- Flexbox and CSS Grid layouts
- Responsive media queries
- Keyboard focus styles
- Dark mode support through system preferences
- CSS animations and transitions

## How to View

Open `index.html` in a web browser and navigate to the exercises.
